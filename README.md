# AetherNG 🛒

A modern minimalist e-commerce web app built with React + Vite.

## 🚀 Features
- Product browsing
- Cart system
- Wishlist
- Authentication UI
- Recently viewed products
- Responsive design

## 🛠️ Tech Stack
- React
- Vite
- Context API
- CSS

## 📦 Installation

```bash
git clone https://github.com/Ellis-Nz/AetherNG.git
cd AetherNG
npm install
npm run dev
